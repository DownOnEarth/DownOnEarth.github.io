FTP

Documentation

Interesting ports

  • 21 TCP - FTP control channel, client sends commands, server returns status codes
  • 20 TCP - Data channel, used exclusively for data transmission

Usage

Establishing connection

Using standard FTP client :

ftp <serverIP>

Using Netcat :

nc -nv <serverIP> 21

Connect using TLS/SSL using OpenSSL :

openssl s_client -connect <serverIP>:21 -starttls ftp

Download all files from FTP server allowing anonymous user (can trigger an alert) :

wget -m --no-passive ftp://anonymous:anonymous@<serverIP>

Download all files from FTP server with user on different port (can trigger an alert) :

wget -m --no-passive ftp://<user>:<password>@<serverIP>:2121
