Weierstrass equations

An elliptic curve EE is the set of solutions (together with the point at infinity OO) to a Weierstrass equation:

E:Y2=X3+aX+bE:Y^2=X^3+aX+b

To ensure there are no singularities on the curve, the constants a,ba,b must satisfy:

4a3+27b2≢0(modp)4a^3+27b^2\not\equiv 0\pmod p

Point Addition

On elliptic curves, it is possible to define an operator called point addition (+)(+) such that taking the set of points on an elliptic curve, (+)(+) defines an Abelian group operation.

The point at infinity OO is a single point located at the end of every vertical line at infinity. It acts as the identity element of the group.

Elliptic curves over Fp\mathbb F_p

In Elliptic Curve Cryptography (ECC), elliptic curves are studied over a Finite Field Fp\mathbb F_p, therefore the curve will become a collection of points whose x,yx, y coordinates are integers in Fp\mathbb F_p. The set (E(Fp))(E(\mathbb F_p)) of (Fp)-rational(\mathbb F_p)\text{-rational} points is finite.

E(Fp)={(x,y) : x,y∈Fp,y2=x3+ax+b}∪{O}E(\mathbb F_p)=\{(x,y)\ :\ x,y\in \mathbb F_p,\quad y^2=x^3+ax+b\}\cup \{O\}
