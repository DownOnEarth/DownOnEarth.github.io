For a prime pp, the set Z/pZ\mathbb Z/p\mathbb Z is the set of residue classes modulo pp and can be represented by {0,1,…,p−1}\{0,1,\dots,p-1\}. With operations (+,×)(+,\times) modulo pp, Z/pZ\mathbb Z/p\mathbb Z is a finite field.

Z/pZ={a+pZ : a∈Z}\mathbb Z/p\mathbb Z=\{a+p\mathbb Z\ :\ a\in\mathbb Z\}

Each residue class is identified with its canonical representative in {0,1,…,p−1}\{0,1,\dots,p-1\}.

Primality is important because:

∀a∈Z/pZ∖{0},∃a−1∈Z/pZsuch thata×a−1≡1(modp)\forall a \in \mathbb Z/p\mathbb Z\setminus \{0\},\quad \exists a^{-1} \in \mathbb Z/p\mathbb Z \quad\text{such that}\quad a\times a^{-1}\equiv 1 \pmod p

Congruence modulo pp is defined as:

a≡b(modp)  ⟺  p∣(a−b)a \equiv b \pmod p \iff p\mid(a-b)

Note that, for 0<a<p,(−a) mod p=p−a0<a<p,\quad (-a)\bmod p=p-a.

Addition

For a,b∈Z/pZa,b\in \mathbb Z/p\mathbb Z the addition c≡a+b(modp)c\equiv a+b\pmod p is computed as:

x=p−a,c={a+b,b<xb−x,b≥xx=p-a,\quad c=\begin{cases}a+b,\quad b<x\\ b-x,\quad b\ge x\end{cases}

This is done as a practical way to avoid computing large numbers such as (a+b)(a+b) overflowing what an integer can encode.

Subtraction

Subtraction is achieved by using the additive inverse:

a−b=a+(−b),b+(−b)≡e(+)≡0(modp)a-b=a+(-b),\quad b+(-b)\equiv e^{(+)}\equiv0\pmod p

Multiplication (double and add)

Multiplication can be viewed as repeated addition:

a⋅b=a+a+⋅⋅⋅+a⏟b timesa\cdot b=\underbrace{a+a+\cdot\cdot\cdot+a}_{b \text{ times}}

However, for b≥1b\ge1, repeated addition requires b−1b-1 additions. As every nonnegative integer can be written as the sum of powers of 22, if we take the binary form of the multiplier bb, it is possible to reduce the computation to:

a⋅b≡∑i=0kbi2ia(modp),bi∈{0,1}a \cdot b\equiv \sum_{i=0}^{k}b_i 2^i a \pmod p,\quad b_i \in \{0,1\}

where kk is the index of the most significant bit of bb, this reduces the number of modular additions from O(b)\mathcal{O}(b) to O(log⁡b)\mathcal{O}(\log b).

Division

Division is achieved by using the multiplicative inverse

ab=a×b−1,b≠0,b×b−1≡e(×)≡1(modp).\frac ab = a\times b^{-1},\qquad b\ne0,\qquad b\times b^{-1}\equiv e^{(\times)}\equiv1\pmod p.

Exponentiation (square and multiply)

Exponentiation can be viewed as repeated multiplication:

ab=a×a×⋅⋅⋅×a⏟b timesa^b=\underbrace{a\times a\times\cdot\cdot\cdot\times a}_{b \text{ times}}

However, for b≥1b\ge1, repeated multiplication requires b−1b-1 multiplications. As every nonnegative integer can be written as the sum of powers of 22, if we take the binary form of the exponent bb, it is possible to reduce the computation to:

ab≡∏i=0kabi2i(modp),bi∈{0,1}, b∈Z≥0a^b\equiv\prod_{i=0}^{k}a^{b_i 2^i} \pmod p,\qquad b_i \in \{0,1\},\ b\in\mathbb Z_{\ge0}

where kk is the index of the most significant bit of bb, this reduces the number of modular multiplications from O(b)\mathcal{O}(b) to O(log⁡b)\mathcal{O}(\log b).
