Overview

Documentation

Interesting ports

  • TCP/1521 - Default port listening for incoming connections, can be changed and configured over TCP/IP, UDP, IPX/SPX, and AppleTalk.

Usage

SQLplus

Connect to Oracle database :

sqlplus <user>/<password>@<serverIP>/XE

Login as other user, if appropriate privileges are granted :

sqlplus <user>/<password>@<serverIP>/XE as <otherUser>

Once the connection is established, SQL requests can be run :

select name, password from sys.user$;

Common errors

SQLplus

Error while loading shared libraries :

sudo sh -c "echo /usr/lib/oracle/12.2/client64/lib > /etc/ld.so.conf.d/oracle-instantclient.conf"; sudo ldconfig

Usage

Nmap

SID brute-forcing :

sudo nmap -p1521 -sV <target> --open --script oracle-sid-brute

Odat

Ennumeration tool, run all modules :

./odat.py all -s <target>

Upload a file :

./odat.py utlfile -s <target> -d XE -U <user> -P <password> --sysdba --putFile <serverLocation> <newFileName> <fileToUpload>
