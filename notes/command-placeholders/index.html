Command Placeholders

Variables

Each variable is written on the format <variable>

If the variable is a path :

  • <file>-> represents relative file path
  • <filePath> -> represents path + filename (/home/user/file.txt)
  • <filePath/> -> represents only the path (/home/user)
  • <filePath//> -> represents the path with an ending / (/home/user/).
