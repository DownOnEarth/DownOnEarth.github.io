Footprinting and Online Presence

Usage

SSL Certificates

Find subdomains from cret.sh :

curl -s https://crt.sh/\?q\=<domainName>\&output\=json | jq .

Filter by unique subdomains :

curl -s https://crt.sh/\?q\=<domainName>\&output\=json | jq . | grep name | cut -d":" -f2 | grep -v "CN=" | cut -d'"' -f2 | awk '{gsub(/\\n/,"\n");}1;' | sort -u

Shodan

Search from IP list file TCP/IP opened ports :

for i in $(cat <IPAddressesFile>);do shodan host $i;done

DNS Record

Dig a domain name :

dig any inlanefreight.com
  • A : IP addresses that point to a specific (sub)domain.
  • MX : Mail server used.
  • NS : Domain Name Server used (FQDN to IP address resolution)
  • TXT : verification keys for different third-party providers and other security aspects of DNS (SPF, DMARC, DKIM - responsible for verifying and confirming the origin of sent emails)
