Interesting ports

  • TCP/873 - Default Rsync port

Usage

List opened share :

rsync -av --list-only rsync://<serverIP>/dev

Sync files to local :

rsync -av rsync://<serverIP>/dev

Sync files over SSH :

rsync -av -e "ssh -p<port>" rsync://<serverIP>/dev
