Basic Fuzzing

Usage

Search directories :

  • FUZZ an arbitrary keyword
  • -ic parameter to not display banner
ffuf -w <wordlist>:FUZZ -u http://<serverIP>:<port>/FUZZ

Use extension wordlist to find website extension (index file is used as it is the more common) :

ffuf -w <wordlist>:FUZZ -u http://<serverIP>:<port>/<directory>/indexFUZZ

Search with found extension ( .php, .js, .asp/x, …) :

ffuf -w <wordlist>:FUZZ -u http://<serverIP>:<port>/<websiteFolder>/FUZZ.<extension>

Recursive search :

  • -v to output full URLs
  • <extension> on the format .php or ".php,.php7,..."
ffuf -w <wordlist>:FUZZ -u http://<serverIP>:<port>/FUZZ -recursion -recursion-depth 1 -e <extension> -v

Domain Fuzzing

Usage

Search for sub-domains :

ffuf -w <wordlist>:FUZZ -u https://FUZZ.<domain>/

Search for VHOSTS (fuzzing on HTTP header Host:), filter by size to remove uninteresting results :

ffuf -w <wordlist>:FUZZ -u http://<domain>:<port>/ -H 'Host: FUZZ.<domain>' -fs <size>

Parameter Fuzzing

Usage

GET Method

Search for parameters, filter by size to remove uninteresting results :

ffuf -w <wordlist>:FUZZ -u http://<domain>:<port>/<directory>/<page>?FUZZ=key -fs <size>

Search for a specific key (id - local file inclusion payloads for example) :

ffuf -w <wordlist>:FUZZ -u 'http://<serverIP>:<port>/<page>?id=FUZZ' -fs <size>

POST Method

Search for parameters, filter by size to remove uninteresting results :

ffuf -w <wordlist>:FUZZ -u http://<domain>:<port>/<directory>/<page> -X POST -d 'FUZZ=key' -H 'Content-Type: application/x-www-form-urlencoded' -fs <size>

Search for a specific key (id) :

ffuf -w <wordlist>:FUZZ -u http://<domain>:<port>/<directory>/<page> -X POST -d 'id=FUZZ' -H 'Content-Type: application/x-www-form-urlencoded' -fs <size>

Server Files (from LFI)

Usage

Server Webroot

Locate absolute path of index.php :

ffuf -w <wordlist>:FUZZ -u 'http://<serverIP>:<port>/<page>?<vulnerableParameter>=../../../../FUZZ/index.php' -fs <size>

if not found, we may search for server configuration files.

Server logs/configurations

Locate logs and configurations files :

ffuf -w <wordlist>:FUZZ -u 'http://<serverIP>:<port>/<page>?<vulnerableParameter>=../../../../FUZZ' -fs <size>
