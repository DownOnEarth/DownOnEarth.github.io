Cracking Modes

Usage

Single crack mode

Basic brute-force attack :

john --format=<hashType> <hash or hashFile>

Wordlist mode

Basic dictionary attack (multiple wordlists can be specified, separated by ,) :

john --wordlist=<wordlist> --rules <hashFile>

Note : rules can be applied to generate candidate passwords using transformations such as appending numbers, capitalizing letters and adding special characters.

incremental mode

Try all possible combinations from a character set :

john --incremental <hashFile>

Note : default character set (a-zA-Z0-9). Resource intensive mode, every combination is made in sequence starting from the shortest one.
