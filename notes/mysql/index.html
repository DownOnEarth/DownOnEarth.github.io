Usage

MySQL Client

Connect to database :

  • -p to specify password, inline use with -p<password>
  • -h to specify host, localhost if not added
mysql -u <user> -h <host> -P <port> -p

INFORMATION_SCHEMA database

INFORMATION_SCHEMA contains metadata about the databases and tables present on the server, useful to get :

  • List of databases
  • List of tables within each database
  • List of columns within each table
SCHEMATA

Get all the databases names :

SELECT schema_name FROM information_schema.schemata;
TABLES

Get the structure of a database :

SELECT table_name, table_schema FROM information_schema.tables where table_schema='<database_name>';
COLUMNS

Get the columns of a table :

SELECT column_name, table_name, table_schema FROM information_schema.columns where table_name='<table_name>';
