R-services

Documentation

Interesting ports

  • TCP/UDP/512-514 - port range of R-services

R-commands (most common)

  • rcp (remote copy)
  • rexec (remote execution)
  • rlogin (remote login)
  • rsh (remote shell)
  • rstat
  • ruptime
  • rwho (remote who)

Usage

Login :

rlogin <serverIP> -l <user>

List authenticated users :

rwho

List authenticated users (more detailed) :

rusers -al <serverIP>
