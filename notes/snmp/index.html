Documentation

Interesting Ports

  • 161 UDP - Transmission of control commands using agents (client to server)
  • 162 UDP - Traps, data packets sent from the SNMP server to the client without being explicitly requested

Usage

Snmpwalk

Tool to query the OIDs with their information :

snmpwalk -v<SNMPVersion> -c <communityString> <serverIP>

Onesixtyone

Tool used to brute-force the names of the community strings :

onesixtyone -c <wordlist> <serverIP>

Braa

Tool to brute-force individual OIDs from community strings

braa <communityString>@<serverIP>:.1.3.6.*
