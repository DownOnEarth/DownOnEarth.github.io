The Batch-Learning problem in Time Series Forecasting

Time series forecasting models trained offline (batch-learning) fail when the data distribution changes in evolving real-world environments (weather patterns, traffic flow, financial market evolution). One solution is online learning with methods such as OTTA and Online Time Series Forecasting, however these methods have drawbacks that need to be addressed. The former are primarily designed for images and do not consider the specific characteristics of time series, the latter rely on updating the model with each newly collected sample, which may be problematic when it deviates from the historical data distribution (or contains noise), leading to a worse generalization performance.

Online adaptation approaches

  • Online Time Series Forecasting: updating using true labels once available.
  • Online Test-Time Adaptation: adapting during inference, without labels.

Model Overview and Components

The model can be subdivided into three main components :

(THSS) Transferable Historical Sample Selection

As data distribution keeps changing, not all past data is useful, THSS is a method to select the most relevant historical samples by comparing latent representations of past and current data (and choosing the closest ones to the current distribution).

The selected data subset will then be used for :

  • Data augmentation (TOA) ;
  • Batch update at test time.

Process

  1. Store historical samples into a Memory Bank MM (First-In-First-Out) ;
  2. Generate embeddings with a mapping model E(⋅)E(\cdot) that preserve semantic consistency (pre-trained VAE encoder) :
    • test sample →E(xt)=zt\rightarrow E(x_t) = z_t
    • historical sample →E(xi)=zi,∀i∈M\rightarrow E(x_i) = z_i,\quad \forall i \in M
  3. Compute cosine similarity between ztz_t and every ziz_i ;
  4. Select top nn samples XhX_h.

(TOA) Transferable Online Augmentation

TOA is a data augmentation method that creates a batch of training samples at test time by mixing the current sample with selected historical samples (THSS) in the frequency domain (amplitude + phase) instead of the time domain (which could harm underlying structure). As test-time data distribution diverges from historical data, generating synthetic samples permits to better approximate the current distribution.

This method achieves batch learning in a streaming (constant flux of data) environment, reduces noise impact, handles distribution shifts (relevant historical data) and preserves time series structure (frequency domain).

The TOA mechanism is done at inference time but the calculated batch provides no benefit until the training phase (at time t+Ht+H, when the ground truth is available) unless the forecasting model leverages it (e.g. batch normalization, entropy minimization, self-supervised reconstruction). At training time, the batch is used to improve learning stability and distribution matching (noise reduction, better gradient estimation, distribution shift adaptation, etc.).

Process

  1. Inputs :
    • Current test sample Xt={xt}X_t = \{x_t\}
    • Selected historical samples XhX_h (THSS)
  2. Convert to frequency domain using Fast Fourier Transform (FFTFFT), with A(⋅),P(⋅)A(\cdot),P(\cdot) the amplitude and phase :
    • FFT(xi)=A(xi)⋅ejP(xi),xi∈Xh∪XtFFT(x_i) = A(x_i)\cdot e^{jP(x_i)},\quad x_i \in X_h \cup X_t
  3. Mix amplitude and phase separately, with X+X_+ the augmented sample set and λ\lambda an hyper-parameter representing the mixing coefficient :
    • A(X+)=λaA(xt)+(1−λa)A(xh),∀xh∈XhA(X_+) = \lambda_aA(x_t) + (1-\lambda_a)A(x_h),\quad \forall x_h \in X_h
    • P(X+)=λpA(xt)+(1−λp)A(xh),∀xh∈XhP(X_+) = \lambda_pA(x_t) + (1-\lambda_p)A(x_h),\quad \forall x_h \in X_h
  4. Mixing weights λa,λp\lambda_a, \lambda_p depend on latent space similarity between ztz_t and every zh=E(xh)z_h = E(x_h), and a defined threshold τ\tau :
    • Similar distributions (distance<τdistance < \tau) : Uniform mixing, more influence from historical samples.
    • Distribution shift (distance>τdistance >\tau) : Gaussian (high mean, low standard deviation), more influence from current sample.
  5. Convert back to time domain :
    • x+=FFT−1(A(x+)⋅ejP(x+)),x+∈X+x_+ = FFT^{-1}(A(x_+)\cdot e^{jP(x_+)}), \quad x_+ \in X_+
  6. Batch update : feed Xb=X+∪XtX_b = X_+ \cup X_t as a batch to update the model.

Prediction Module and Training

The prediction model is a forecasting module that takes XbX_b (from TOA) as input and outputs future predictions. It has two components : series decomposition and a two-stream forecaster.

Series Decomposition

The input XbX_b is split into :

  • Trend component (long term trend) : Xr=AvgPool(Padding(Xb))X_r = AvgPool(Padding(X_b))
  • Seasonal component (cyclical relationship) : Xs=Xb−XrX_s = X_b - X_r

Two-stream Forecaster

The components Xr,XsX_r, X_s are fed into a two-stream forecaster with identical structures, the final prediction is the sum of both outputs. The forecaster can be any Time Series model (accepting batch input and supporting gradient updates on batches).

Y^=Forecasterr(Xr)+Forecasters(Xs)\hat{Y} = Forecaster_r(X_r) + Forecaster_s(X_s)

Loss Compute

Once the model has made his predictions, the loss (L2) is computed as follow :

L=1N∑j=1N∥Y^1:Hj−Y1:Hj∥2\mathcal{L} = \frac{1}{N} \sum_{j=1}^{N} \left\| \hat{Y}_{1:H}^{j} - Y_{1:H}^{j} \right\|^2

With :

  • NN the number of channels in the time series ;
  • HH the forecasting horizon.

The model parameters are then updated.

Forecasting accuracy under distribution shifts

BTOA adapts faster to distribution shifts (loss curve peaks) on highly non-stationary datasets than baselines. Distribution shifts in features are obtained by comparing 200 time-point samples before and after loss curve peaks.

Comparison of BTOA with baselines using a forecasting windows H=96H=96 on samples selected from the post-peak loss curve period (adaptability after distribution shifts). BTOA exhibits a good adaptation and closer alignment with ground truth values than baselines. It seems to be the better model to mitigate negative impacts of distribution shifts and to maintain predictive accuracy over time.

Hyper-parameters

Batch Size

Considering both performance and computational efficiency, a batch size of 16 seems to be the optimal choice. An ideal balance between high model performance and training time, improving the model’s practicality for real-world applications (particularly with large-scale streaming data).

Ablation Study

THSS

THSS module outperforms closest-16 (16 most recent samples) and L2-distance (Euclidean distance between vectors) meaning the VAE successfully captures the semantic information of time series in the latent space, confirming the effectiveness of the latent space.

TOA

Superior performance of the TOA method across all five datasets, this highlights the importance of doing data augmentation in the frequency domain (focusing on amplitude and phase) instead of the time domain (leading to interference between different series).

Conclusion

BTOA is a framework and thus can be added to other models, it has demonstrated a significant effectiveness in improving model performance (adding BTOA outperforms the original versions of TCN and iTransformer). BTOA seems to enhance the models generalization ability and overall performance (against distribution shifts in online time series prediction).
