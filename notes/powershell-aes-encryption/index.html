PowerShell AES Encryption

Usage

Import module :

Import-Module .\Invoke-AESEncryption.ps1

Encrypts the string “Secret Test” and outputs a Base64 encoded ciphertext :

Invoke-AESEncryption -Mode Encrypt -Key "<password>" -Text "<secret>"

Decrypts the Base64 encoded string <base64Encoded> and outputs plain text :

Invoke-AESEncryption -Mode Decrypt -Key "<password>" -Text "<base64Encoded>"

Encrypts the file “file.bin” and outputs an encrypted file “file.bin.aes” :

Invoke-AESEncryption -Mode Encrypt -Key "<password>" -Path file.bin

Decrypts the file “file.bin.aes” and outputs an encrypted file “file.bin” :

Invoke-AESEncryption -Mode Decrypt -Key "<password>" -Path file.bin.aes
